## Ключевые проекты

### [TABD — прогнозирование показателей сети АЗС](https://github.com/Terps489/TABD)

`Python` `PyTorch` `Temporal Fusion Transformer` `pandas` `Dash` `Plotly`

Магистерский ML-проект с полным циклом `train → predict → dashboard`.

- Реализовал квантильный прогноз P10/P50/P90 для девяти целевых показателей.
- Добавил сравнение с дневным и недельным baseline по MAE, RMSE, MAPE и SMAPE.
- Собрал интерактивный дашборд для анализа данных, прогнозов, метрик и важности факторов.
- Подготовил обезличенный пример данных, генератор синтетики, кэширование и сохранение checkpoints.

### [TelegramBotProject — OCR-бот для русского текста](https://github.com/Terps489/TelegramBotProject)

`Python` `aiogram` `EasyOCR` `OpenCV` `pytest`

Модульный OCR-пайплайн с тремя интерфейсами: Telegram-бот, CLI и пакетная оценка качества.

- Реализовал ресайз, deskew, шумоподавление, бинаризацию и словарную посткоррекцию изображений.
- Добавил расчёт CER/WER, CSV-отчёты, конфигурацию через `.env` и модульные тесты.
- Отделил OCR-ядро от Telegram-слоя, чтобы использовать распознавание независимо от бота.

### [IIS Service Classifier — классификация сервисов](https://github.com/Terps489/iis_service_classifier)
